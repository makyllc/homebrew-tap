# makyllc/tap

Homebrew casks by makyllc.

```sh
brew install --cask makyllc/tap/pilcrow
```

| Cask | What it is |
| --- | --- |
| `pilcrow` | [Pilcrow](https://github.com/makyllc/pilcrow-releases), a Markdown writing app with AI coaching |

Use the full name shown above. Homebrew asks you to trust a tap before it accepts a short name.
